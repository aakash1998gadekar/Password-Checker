# Compliance Checklist Tool

A simple CLI tool to help track GDPR/ISO 27001 compliance tasks and generate reports. Designed for security and compliance professionals.

## Features
- Checklist for GDPR/ISO 27001 controls
- Mark items as complete/incomplete
- Generate summary report

## Requirements
- Python 3.8+
- No external dependencies

## Usage
1. Run the tool:
   ```sh
   python checklist.py
   ```
2. Follow the prompts to check off compliance items.
